# patientGenerator

This is a static documentation website for `patientGenerator`.
It is published from `main/docs` and does not execute R code on GitHub.

## What the package does

- `patientChat`: Generate synthetic OMOP CDM patient sets using an LLM.
- `patientDesigner`: Review/edit generated cohorts in a D3/Shiny UI.
- `hecateSearch`: Search OMOP concepts (used by the designer concept lookup).
